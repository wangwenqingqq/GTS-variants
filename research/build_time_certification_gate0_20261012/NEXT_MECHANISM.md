## Frozen minimum correctness, if a subsequent prototype is admitted

Start with one captured D960, 1M-occurrence rebuild, five aligned levels from the parent diagnosis, with duplicate/self occurrences and tie keys included. Preserve native keys, pivot choices, membership, node topology, serialized tree and order **byte-identically**. Preserve every child `lo/hi` endpoint **bit-identically** to B0, and range/kNN outputs identically. No tolerances and no nominal-to-interval substitution.

Use the exact refit arithmetic expression, coordinate/reduction order, precision promotions, compiler flags, and rounding intrinsics. Shared loads do not imply shared arithmetic: the FP32 nominal subtraction must remain native, and the FP64 endpoint path must remain unchanged. NaNs, signed zero, infinities, and invalid-data policy must be handled exactly as the keeper, not assumed away. Carry sidecars by occurrence ID without changing sort value layout/tie behavior unless byte-identical ordering is separately proved. Parent scoring ownership changes to child reduction ownership after split; pair identity alone is not the child map.

The 16 MB/level figure is only `1,000,000 × 2 × 8` decimal bytes of endpoints. Charge alignment, extra writes/reads, permutation and occurrence mapping, sort scratch, reductions, allocation, synchronization, register pressure, and spills. Prove scratch lifetimes; do not infer one-level peak memory from a local variable.

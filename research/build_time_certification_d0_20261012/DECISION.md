# D0_KILL

**Stop the current build-time-certification differentiation thesis before implementation.** Compared with strongest ordinary C2, retained B1 Z removes **no necessary dependency** while preserving the same proposed native-order and final lo/hi contract. Normalized nodes, edges, memory lifetime, child ownership and readiness are identical; the label/kernel placement is not a new mechanism.

## Evidence chain

1. Frozen keeper source distinguishes nominal FP32 subtraction/double scoring accumulation, separate float boundary arithmetic, and ordered directed FP64 refit. B0 per-pair endpoints are register-local.
2. The inherited R1/R2 pair diagnosis supplies 5M scoring and 5M refit tasks with 100% multiset identity overlap and zero same-owner matches. These are inherited pair facts, not newly measured runtime or proof of per-child membership stability.
3. Strong C2 can keep endpoints by physical row and consume native `id_list` and child `[lid,lid+size)` segments. An added million-entry owner map and endpoint sort payload are unnecessary. Ordinary block reduction can share split placement, so a standalone reducer is not a mandatory dependency either.
4. Z's complete graph is identical to that strong control. Pinned CUB primitives independently establish the ordinary segment/block reduction component.
5. X0 fails only the specified one-producer/unchanged-completed-kernel/no-persistent-information model; X1 restores the coordinate sweep. Y0 fails scalar-only exact reconstruction by an algebraic collision witness. No constructive Y1 residual/adaptive producer is admitted; its existence/cost remains unknown, not disproved.

## Material caveats

This is not a theorem that all possible build-time certificates, compressed state, error-free transforms or adaptive extremum filters are impossible. The scalar witness rejects a specific information source; the lifetime argument assumes the unchanged native-kernel boundary and no replay. Sixteen MB is an uncompressed two-double sidecar representation, **not** an information-theoretic minimum. C2 itself remains an unimplemented strong design control; later-level membership stability and compiler/native-key bit identity require explicit qualification. Z shares those obligations and obtains no differentiation from them.

## Reopen only with constructive evidence

A replacement proposal must name a nonempty deleted **strong-C2** dependency, show where sufficient exact information survives across sort/ownership, price added state/recomputation/readiness, and preserve native keys/tie order/pivots/float boundary/topology plus final node lo/hi bits. If it computes only extremal certificates, prove non-extremal elimination cannot change final extrema and specify the fallback. Then run only that mechanism's prior-art mini-gate before any implementation. Missing evidence is uncertainty; it is not authorization for a broad expensive campaign.

Until that design gate is passed, no prototype, full campaign, external rerun or paper prose is authorized by this record.

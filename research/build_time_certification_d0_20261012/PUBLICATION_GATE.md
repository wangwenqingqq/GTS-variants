# Publication boundary

Ship only this task's original English design prose, contract, graph/cost/decision metadata, source hashes/locators, standard-library record validator and ignore rule. The validator contains the exact named whitelist. Full private keeper copies, original supplied plan, primary HTML/source downloads, previous dataset captures, account receipts, hardware/configuration, raw conversation and credentials remain outside the ship set under ignored `local/` or their previous protected locations.

The record makes no anonymous-submission/publication-status change. Preserve the existing corresponding repository's ownership and visibility; use a task branch, no force push/default merge. Review the staged exact path set and hashes, validate a clean archive, scan new payload and all history, obtain an independent read-only scientific/disclosure audit and independently verify its findings before upload. Existing identity metadata and legacy scanner false positives must be individually classified; a nonzero scanner return is not a clean-scan claim and does not authorize history rewriting.

This defines publication gates, not their completion. Private receipts and the final handoff distinguish committed, pushed and independently read-back state. No source implementation or paper edit is part of this delivery.

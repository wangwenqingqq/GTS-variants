L2Unexpanded container remains pinned. The original CUB complete-output kernels
are included verbatim and run on each contiguous native output row. No library
heuristic, device kernel, layout, precision or tree implementation changes.

processes and previous binary/library/data/payload pins qualify it independently.

the byte-identical prior host executable. Query/squared workspace expansion is
outside query timing and charged/disclosed in setup. Query H2D, native pairwise,
complete compaction/fields/observer/D2H and host completion remain inside ACK.

queries cycle across contiguous groups. B64/128 use a separately registered
128-query extension containing96 new independent query rows. Within an invocation
every query is distinct; repeated invocations are disclosed, not new independent

loads can make FLOPs/query and DRAM/query fall together. That would fail CONFIRM,
not prove no padding. The conservative residual decision is PARTIAL, with this
strongest alternative explicit. Kernel counters use all distance launches in the
selected invocation, never a favorable function subset. Full module-image hashes
remain required where acquisition exists, otherwise the boundary stays explicit.

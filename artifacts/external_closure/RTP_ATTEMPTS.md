## Offline/public gate hardening (no measurement replacement)

Review found that the original recovery route did not compare every registration
field and rewrote the identical first command record. The public route now requires
the exact successful first-case prefix, every immutable registration field and
read-only equality for an existing command. Executed original/resume/primary
drivers remain separately hashed. Final analysis binds original receipts and
commands, modes, placement and both registrations; it never relabels the repaired
public source as the original executed source.

The inherited complete-answer path now also requires observe=true, exact delivered
item counts and finite/nonnegative ACK, rebuild, stage, usage and scope timings.
Negative test fixtures reject missing counts, NaN, negative costs and a recovery
with different placement. This is post-hoc validation hardening, not a new timing
run or new estimator.

# Validation scope

## Measurement and observation

- Exact parent, all32 queries, radius/cutoff, original row occurrences, data/full-score
  hashes, 120 x 32B geometry and exact byte baseline frozen before populations.
- Human-approved uncovered-robustness UNCLASSIFIED stop and conditional selected-value
  retention scope; no GO threshold relaxed or rounded.
- Primary-source novelty triage admits CPU characterization only. Numeric CONDITIONAL
  does not trigger the dedicated post-GO audit; no novelty verdict invented.
- Target CPU g++13.3.0 strict FP64 build; four OpenMP workers, nice10, BLAS1,
  ordinary non-optimized Python, empty GPU visibility. No install/settings changes.
- Original272 plus new272 native fixture rows/invocation: stable grouped selection,
  ordered bits, subset safety, ties, equality, duplicate occurrences, signed zero,
  subnormal, extreme finite, nonfinite and invalid-index/budget guards.
- A and B each independently qualify all32 x first4096 rows before full population.
- Exactly one A and one B full population, no failed/replacement/retry population.
  A full scores bit-match all32M frozen references; B0 counts match every parent query;
  all B0/O2/S1 partials are safe with zero false rejection. Zero oracle-rounding ambiguity.
- Data, references, all parent and four measurement-source identities unchanged
  before/after; same qualified native binary reused in B.
- Saved-array observer hashes and verifies 96M partials without search replay;
  public stdlib checker separately verifies exact gates, counts, byte denominator,
  conditional geometry, sector ownership, quantiles and overlap.
- Independent read-only audit verifies all96M saved partials and reconstructs all32
  query sector choices from frozen moments/original queries. Fresh whitelist-copy
  native fixtures pass and its binary matches the population binary byte-for-byte.
  The raw, clean-copy and four-figure visual/style receipts are recorded separately.
  Local validation is not confirmation of GitHub upload.
- Two closure-only operational issues were retained and repaired without candidate
  rerun: an incomplete source-tree receipt lookup, and a conservative figure-edge
  guard catching a ylabel before final padded renders. Neither relaxed a gate.

## Not run / not established

CUDA, NCU/NSYS, GPU sanitizer/stress, physical sectors/DRAM, latency, sustained
workloads, full fallback and complete range-result construction: **NOT_RUN**.
No kNN, insert/delete trace, larger query pool, alternate grouping/budget/score,
layout transformation, per-object summary or manuscript edit.

Conditional source-byte savings assume no selected-coordinate reread. Retention,
original-order full reconstruction, shared/register pressure, spills, compaction,
outputs, launches and host waits are unknown, not zero. Nominal aligned sector
geometry is not a physical transaction or complete-search traffic upper bound.

Raw inputs/proofs and primary PDFs remain private, so public scalar checks alone
cannot reproduce every data-level validation. Neither exact-sector novelty nor
universal family failure is established by this CONDITIONAL implementation gate.

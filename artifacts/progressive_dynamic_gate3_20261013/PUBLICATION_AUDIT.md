# Scoped publication gate

The task-owned Gate3 directory is the only publish set. `PUBLICATION_SET.json` enumerates every intended file with bytes and SHA256; it excludes its own hash to avoid a circular manifest. No old cache, unrelated campaign, library/binary, vector payload, raw private receipt, manuscript or Overleaf file is included. Existing repository visibility is public and is preserved. No history rewrite, repository deletion, automatic merge or new license is performed.

# Remaining provenance gate — not an execution authorization

The source inspection is complete for the current CPU-only contract. It explains tile size, arithmetic, resource geometry and the traffic confound. It does not authorize a new benchmark or optimization.

1. **Exact module acquisition only.** If continued acquisition is requested, freeze a separate one-process diagnostic: same binary, libraries, semantic inputs, device admission and output oracle. Capture the naturally loaded JIT-LTO cubin through an available official module callback/source-export mechanism; correlate module ID → function ID → selected launch. Do not patch the library or hook a foreign process. Prefer existing trace/report evidence before a new launch. Record full module SHA256, selected-function normalization, acquisition tool/version and failure boundary. Do not use callback/profiler duration as latency.
2. **No automatic gate repair.** Even exact module acquisition cannot make the old traffic separation pass. Preserve `PARTIAL_PADDING`; any new orthogonal causal test requires a prospectively registered contract and explicit explanation of how padding and database reuse are separated. Do not relabel the 75 previous processes.
3. **Prior-art before implementation.** A detailed prior-art/novelty kill test is still conditional on admission under a new, justified contract. Issue #277 is about outer brute-force kNN output tiling and its Faiss/GEMM route, not evidence that this `L2Unexpanded` inner contraction has the same bug or an applicable fix. No heuristic change or known-fix substitution is admitted here. [Issue #277](https://github.com/NVIDIA/cuvs/issues/277).
4. **Baseline, not novelty.** A proper same-semantics small-B path, if established later, is baseline strengthening first. Requalify complete members and distance fields, then compare against a fresh native keeper under the same full-output ACK. Do not substitute expanded-L2/inner-product arithmetic, batching throughput, or kernel-only duration for the existing B1 semantic/latency contract.

Stop if the exact module cannot be recovered without a broader intervention; retain source-supported evidence and the unknown module boundary. No tree, compression, Tensor Core, paper, or long matrix work is part of this continuation.

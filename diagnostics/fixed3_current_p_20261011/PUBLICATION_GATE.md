# Publication gate

Existing corresponding repository and authenticated owner/push rights verified;
visibility preserved as public. Named experimental branch only, no force/merge.
Only this task directory is staged; unrelated parent changes are preserved.

Full ref/reflog history was scanned. The generic scanner flags existing public
author email metadata and a previously published curator's literal generic
redaction regex (not an actual personal pathname). These were independently
inspected as documented false-positive/public-identity exceptions, not scrubbed
from user history. No attribution trailer, credentials or new private paths
are admitted. The outgoing whitelist additionally rejects raw GPU UUIDs,
private home/IP paths and secret-shaped tokens. Exact measurement contracts,
private command logs, data, binaries and profiler reports remain outside Git.

A read-only independent audit checked mapping/barriers, controller gates,
public UUID view, recovery and claims. All leads were independently verified;
resource/property blocks, payload hashes, external inputs/reference closure and
CPU unit byte reconstruction are retained. No audit substitutes for GPU gates.

Release recipe changes (UUID hash guard, exact resource parser, fresh input
whitelist) are explicitly distinct from the immutable executed recipes; no
performance sample or kernel was replaced. Public replay is tested from the
committed archive before upload. Upload remains separate from default-branch
merge, paper synchronization, or submission.

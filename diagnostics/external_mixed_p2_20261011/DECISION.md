# Decision

- **Implementation:** freeze P2 unchanged. No source, binary, maintenance policy
  or comparator optimization occurred during the campaign.
- **External positioning:** rejected for parity/superiority on the registered
  short GIST mixed service: P2/E 4.179321, CI [4.145628,4.227814], P2 wins 0/6.
  This does not reject Fixed3's prior internal gain or all GPU tree indexes.
- **Attribution:** measured ACK excess is 67.04% native maintenance, 32.16% range,
  0.66% KNN. Output memcpy waits mostly overlap KNN compute; do not classify them
  as an independent CPU output algorithm bottleneck.
- **Next direction (inference, not executed):** test a non-incremental reduction
  in the measured rebuild/refit/refresh physical work or need/frequency, with
  identical logical visibility. Run prior-art/novelty Gate 0 and a cheap kill
  test before large experiments. Range traversal/verification is the secondary
  question; another packing-factor sweep is not justified here.
- **Do not revive:** old external ratio divided by Fixed3 gain; ANN or finite-K
  range; mandatory scan-tree rebuild; memcpy CPU-wait plus GPU duration; a >3x
  ratio used as proof of an inherent pruning limit.
- **Reopen condition:** genuinely different workload/maintenance policy or a new
  mechanism with explicit source identity, same contract, correct full outputs,
  current comparator remeasurement and decisive complete-service advantage.

The measured primary is trace minus measured final-state/release interval; a
small final fence/clock tail remains, explicitly recorded. This scope is not an
exact isolated last-ACK marker. Only process variability on one fixed trace/GPU
is covered; no sustained or broader product admission is made.

# Publication gate

Verified corresponding GitHub repository/account and push rights; preserve its
existing public visibility. Publish only the new task directory on a named
experimental branch, with no force, automatic merge or old-work sweep.

Full reachable/ref-log history scan identifies the previously public author
email metadata and the earlier curator's literal generic redaction expressions.
These are independently inspected historical exceptions, not new leaked roots
or credentials; user history is not rewritten. The exact new whitelist rejects
private homes, IP/device UUID literals, credentials and attribution trailers.
Immutable commands, unredacted sources, binaries and profiler outputs remain in
private raw storage. Public manifests contain relative names and hashes only.

An independent read-only publication audit rechecks statistical scope/direction,
actual timer sources, qualifier/formal receipts and raw output binding, source
hashes, NSYS per-query copies and claim boundaries. Findings must be reverified
and reflected in the exact publish set; no audit substitutes for GPU gates.

The clean committed archive is CPU-tested and its intended files independently
verified at the pushed revision. A pushed experimental branch is not a merged
release, paper synchronization, submission or universal product qualification.

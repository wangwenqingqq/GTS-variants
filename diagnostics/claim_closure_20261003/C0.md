# C0：版本、契约与兼容性决定

This fills §3 system identity; qualifying evidence is missing because separately measured components do not share one query/update entry.

本轮不把最新HEAD命名为完整GTS++。上游原版固定为`3bac1b725e92e98e3b69d5cb79ad9c56ccb5e639`，八个文件见[ORIGINAL_SOURCE](ORIGINAL_SOURCE.json)。原生main输出静态range计数、kNN第K距离、更新range计数；完整输出适配器必须另列。`#define short float`保持原样，本轮实际数值存储为FP32。

静态range冻结FP32输入、逐坐标显式RN FP64平方累加、inclusive平方半径、按固定id_list输出完整int32 ID与FP32欧氏距离。Host-ready必须含真实有效长度、所有ID/字段D2H与同步。P4 B1/32等已有计时不与kNN混用。

P7冻结K8/32、B1/32、in-database self-inclusive查询，完整交付恰好K个不同int32 ID与有限非负FP32欧氏距离；按距离排序，精确边界允许等距替代ID，自有模式同时检查距离/ID确定顺序。参考显式RN FP64无FMA；原生距离平方字段误差门为`5e-5*max(1,refSquared)`。计时从Host批次ID提交到完整Host输出；冷布局、训练/加载、边界重拟合与Graph捕获单列。参考与完整正式结果见[P7](../unified_knn_e2e_20261003/RESULTS.md)。

U0的原生ID不是稳定外部ID：insert/query参数引用当前物理data_d行；delete参数引用当前存活对象的零基序号；返回ID是当前活多重集的序号。等值重复对象的每个出现有不同序号。删除会压缩序号，重建压缩物理数组，再建立树；查询参数因此也可能指向不同对象。oracle按这些语义逐事件重放，不把原生ID当成原始ID。ACK定义为串行循环进入下一事件的程序点；触发重建时，getNewData和indexConstru均在此之前完成并同步。没有并发或时间隔离的保证。

现有接口未接收新向量与外部ID，因此本轮真实新对象到达不准入。缓冲中的已知物理行可以位于查询所到树叶的覆盖之外，但缓冲独立扫描；该测试不等于树内新增未知向量。U0选择整数坐标、精确整数平方距离oracle；完整ID检查不能由静态tie-aware召回或计数代替。

| 共用部件 | 源码核对与兼容性 | 更新后的失效条件 |
|---|---|---|
| P0–P3/P4排列、AoSoA32 | p4_bench直接include batch_bench，共用固定id_list、打包数据与collector；树dump逐项要求排列相同 | 任意重建/压缩必须原子替换排列、打包数据、ID映射；现有执行器无此协议 |
| 浅层树、向外边界 | P4按每层实际成员覆盖检查、refit_bounds建立FP64误差包围；不同pivot仅按真实ID核对复用 | 插入改变覆盖、删除/重建改变成员与节点映射，需要重新拟合，不得沿用旧证书 |
| workspace/collector | P4与SCAN共用每batch clear、prefix、有效长度D2H，再完整输出；query状态不能泄漏 | N/B/排列变化导致容量与输出映射更新；tombstone必须统一过滤 |
| CUDA Graph | 捕获固定地址、形状和依赖；P7输入H2D已与Graph置于同流 | 数据/树/输出缓冲重分配后必须更新或重捕获；不可仅修改N |
| Tloc dead-count移除 | 是单独历史原生查询修补；P4已使用不同两阶段collector | 不可直接删除当前实际长度反馈，不能把Graph/pooling统称融合 |
| P7 topK/seed | seed引用现有固定ID，参考算术与固定tie排序已验证 | 删除seed或更换数据后上界、合法ID集、树与选择器均需重新校验 |

决定：保留各静态执行器与原生更新的独立身份，只补U0观察和正确性。没有共享更新失效协议，不硬合并历史模块，不相乘历史加速比。动态性能贡献C3暂不保留；Q0/U1的前置keeper条件不成立。M0取消，保留“共同AoSoA32上的显式跨查询复用”窄表述。K0已有P7实测静态入口，最终失败锚点、强基线优势和掩码负收益均保留。

# 父节点掩码块大小 16–512 扩展实验（4090-left，2026-09-25）

沿用 [父节点距离复用实验](../parent_mask_20260925/RESULTS.md)的现有 10 叉 GTS 树、L2 壳层判定、寄存器 10-bit 子节点掩码、下游整数节点标志、叶处理和 CUDA Graph。本次只改变 `parentMaskWalk<Group>` 的 **每 CUDA 线程块处理的父节点数**，在同一二进制中比较 B16、B32、B64、B128、B256、B512。没有改成二叉树，也没有调用 GEMM。

4090-left 的 RTX 4090 上，每种模式、每个数据集做 3 个独立进程轮次。模式顺序正向、反向、打乱，数据集顺序轮换；每进程预热 8 查询，随后计时 8 个完整热查询，包含 Graph 启动、同步和固定容量结果返回主机。表内延迟是三轮“每轮 8 查询均值”的中位数；相对 B32 的百分比来自同轮延迟比值的中位数。

| 每块父节点数 | GIST 1M×960D | 相对 B32 | Deep 1M×96D | 相对 B32 |
| ---: | ---: | ---: | ---: | ---: |
| 16 | 434.575 ms | +0.28% | 49.355 ms | +0.64% |
| **32** | **433.183 ms** | 基准 | **49.025 ms** | 基准 |
| 64 | 434.122 ms | +0.20% | 49.179 ms | +0.55% |
| 128 | 435.679 ms | +0.56% | 49.406 ms | +0.68% |
| 256 | 439.892 ms | +1.52% | 49.892 ms | +1.64% |
| 512 | 449.126 ms | +3.63% | 50.555 ms | +3.15% |

32 组的中位数最低；64 与 32 接近，两数据集各有 1/3 轮 64 略快，**不能把两者的亚百分比差异当作确定优势**。128、256、512 在两数据集全部三轮均慢于 32；大块越大退化越明显。最后一层有 10,000 个父节点，按 32/64/128/256/512 分组分别只启动 313/157/79/40/20 个线程块。并行块数下降与退化方向一致，但未做占用率剖析，不能定量归因。

全部 36 个正式计时进程、288 个查询均通过 CPU 验证的 count 和完整有序输出哈希，同轮六模式逐查询结果一致。四个新块大小在两数据集上各有一次 8 查询预检；Deep B512 的 8 查询 `compute-sanitizer memcheck` 通过。每次运行前确认无其他 GPU 计算进程，并在运行中监控。逐轮均值、配对比值、二进制哈希和验证摘要见 [EVIDENCE.json](EVIDENCE.json)，复现脚本见 [prepare.py](prepare.py)、[gate.py](gate.py)、[timing.py](timing.py)、[analyze.py](analyze.py)。原始收据保留在远端 `/home/ls/tmp/gts_parent_mask_scale_20260925`；生产代码未改。

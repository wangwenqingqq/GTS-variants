## Guardrails before implementing candidates

1. Freeze self inclusion, duplicate occurrence IDs, distance outputs, logical-delete
   order and post-rebuild identity. Independent full IDs/distances and live-state
   oracle must cover mixed operations, not merely counts.
2. Repair per-leaf result sizing (20-slot stride versus up to64 extra IDs) and
   conservative ancestor/min/max bounds before trusting direct inserts.
3. Keep memory geometry separate from cost: 4 useful bytes/32B sector can mean
   strided access, a scalar broadcast, or only one active lane. Use source plus
   active-lane/shape evidence, not a universal eightfold-speedup calculation.
4. For a candidate, charge packing, scans, added workspace, stores, synchronization
   and CPU delivery to the complete operation. Re-measure a correct comparator
   under the same process order/shape; current diagnostics are not that campaign.

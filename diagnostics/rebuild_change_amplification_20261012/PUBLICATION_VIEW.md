# Publication boundary

Publish only this task's curated docs, frozen contract, observer patch/headers,
CPU readers/checks, source pins, complete summarized counts and snapshot hashes.
The original public repository visibility is preserved; no default-branch merge.

Do not publish binaries, packed coordinates, source raw archives, event vectors,
Host command logs, full hardware UUIDs, private home/host paths, credentials,
old user work or any managed skill/cache content. Complete raw truth is retained
privately. Large pack bytes stay on the host; local verification explicitly
covers only the 174 small archived files. The four packs are bound by full hashes
reverified on the host, not by local byte access.

The repository evidence is a read-only maintenance-state diagnosis, not a paper
novelty artifact, speedup, production keeper or benchmark framework. A new
mechanism must separately pass novelty, correctness, sanitizer, stress and
same-contract end-to-end gates. Original keeper code/binary and prior evidence
remain immutable. CPU post-processing clarification and a preserved closure-tool
failure are disclosed rather than retroactively relabeled as preregistration.
